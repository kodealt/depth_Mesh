# depth MESH
so i have this cool vision
make terrain like meshes, like the ps2's used to have
so i decided to make it
mostly from scratch so that the size is low
-O0 optimization: calculations must be done under 0.01 ms (60+ fps)

openGL for rendering, when it comes to that

to make:

```
git clone https://github.com/kodealt/depth_Mesh.git
```

```
cd depth_Mesh
```

```
g++ -O0 ./depth_Mesh.cc -o ./depth_Mesh
```

then run

```
./depth_Mesh
```
